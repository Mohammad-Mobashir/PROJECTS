# DriveNow – React Car Rental Website

## Run locally
1. Open this folder in VS Code (the folder containing `package.json`).
2. Open Terminal and run `npm install`.
3. Run `npm run dev`.
4. Open the localhost URL printed by Vite.

## Pages and modules
- **Home:** welcome page and featured cars.
- **Cars:** complete car catalogue with category filters and car details.
- **Booking:** select dates and pickup location, calculate the rental total, and submit a booking.
- **Contact:** contact information and a demo contact form.
- **User:** look up bookings using the email address entered during booking.
- **Admin:** view all bookings, update booking status, and delete bookings.

## Important project note
This is a frontend demonstration. Booking records are stored in the browser's `localStorage`, so they remain on the same browser/device. There is no backend database, real user login, secure admin authentication, payment gateway, or email/message delivery. Do not use this demo to collect real customer information.
